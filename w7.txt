Practical No. 7
Aim: Implement a RESTful web service that accepts the details to be stored in a database and performs CRUD operation.

Step-by-Step Implementation Guide
Step 1: Create a New Web Application
1. Open NetBeans IDE and go to File -> New Project... (Shortcut: Ctrl + Shift + N).

2. Select Java Web in categories and Web Application in projects. Click on Next.

3. Enter the project name as CRUDOperation.

4. Click on Next and then Finish.

Step 2: Create an Entity Class
1. Right-click on your project (CRUDOperation) in the Projects window.

2. Select New -> Entity Class... (if not visible, go to Other -> Persistence -> Entity Class).

3. Set the Class Name to Student and the Package Name to com.kk.

4. Click on Next and then Finish.

Step 3: Generate JSF Pages from Entity Classes
1. Right-click on your project name again and select New -> JSF Pages from Entity Classes... (or go to Other -> JavaServer Faces -> JSF Pages from Entity Classes).

2. Select the available entity (Student) and click Add to move it to the selected side.

3. Review or make necessary configurations if prompted, then click on Next and Finish.

Step 4: Create RESTful Web Services from Entity Classes
1. Right-click on your project and select New -> RESTful Web Services from Entity Classes... (or go to Other -> Web Services -> RESTful Web Services from Entity Classes).

2. Select Student and click Next.

3. Provide the package name as com.kk.service and click Finish.

Step 5: Add a Property to Student.java
1. Open the Student.java file from your entity package.

2. Locate the line containing private long (or right-click right after it inside the class body) and select Insert Code... (Shortcut: Alt + Insert).

3. Select Add Property.

4. Set the name to firstid and click OK.

Step 6: Clean, Build, and Deploy
1. Right-click on your CRUDOperation project and click on Clean and Build.

2. Once the build is successful, right-click on the project again and click on Deploy.

Step 7: Run and Test the Application
1. After execution, your default browser will open with the application interface.

2. Click on Show All Student Items to view records.

3. Click on Create New Student, enter an ID and details of your choice, and click Save.

4. You can use the provided options in the interface to View, Edit, or Delete the stored student records.
